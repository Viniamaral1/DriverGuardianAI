# Guardian OS V9.2 — Historical Evidence & Pattern Explainability

Built from the manually tested/passed V9.1 checkpoint.

## Changes
- Similar historical sessions are now clickable and open the underlying Decision Memory replay.
- Each similarity card includes a collapsible "Why matched?" explanation.
- Cross-session patterns now carry supporting Decision Memory session IDs and expose direct evidence links.
- Pattern cards are compact; trend labels are attached to the title as badges.
- Opening historical evidence scrolls to and briefly highlights the Decision Memory panel.

## Safety boundary
No trained-model weights, calibration semantics, Passport validation logic, alert thresholds, V8 Decision Engine calculations, Decision Memory sampling, Predictive Guardian trust gates, or Visual Evidence capture logic are changed by V9.2.
