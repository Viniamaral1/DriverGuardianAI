# Guardian OS V8.4.2 — Replay UI Polish

- Removed the bulky Jump-to-Event button lane.
- Graph hover now shows time, risk, confidence, EAR, baseline EAR and event title.
- Graph click still jumps directly to the nearest Decision Memory sample.
- Event markers remain on the graph itself.
- Evidence player and thumbnails are smaller.
- Event evidence frames preload when selected.
- Playback interval is reduced from 800 ms to 600 ms per frame.
- Slider, Previous/Play/Pause/Next, thumbnail selection and deletion remain.

No changes to the fatigue model, calibration, camera ownership, event thresholds,
alerts, Decision Memory sampling or evidence-capture backend.
