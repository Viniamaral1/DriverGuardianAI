# Guardian OS V6.3.2 — Context Reliability Fix

Fixes only automatic journey context and the Edge page layout.

- Open-Meteo weather code 0 now resolves to Clear instead of Unknown.
- Dry road estimation follows a valid Clear result.
- Saving a new location keeps that location and updates its weather.
- Save and refresh buttons always recover after network errors.
- Automatic weather controls update immediately when switches/location change.
- The manual override switch is larger and no longer cramped.
- Edge Intelligence now uses two independent columns, removing the large gap.

Camera, fatigue model, calibration, profiles, alerts, Commander, reports and
camera environmental perception are unchanged.
